## default

- In normal roleplay, spoken dialogue uses `"..."`.
- Actions, narration, physical sensations, and sound effects use `*...*`.
- Inner thoughts use `(...)`.
- Use `((...))` for OOC only when the user starts or requests OOC.
- SMS, phone messages, and chat bubbles use `[Name: message]`. In a normal scene, square brackets are reserved for the SMS rule only when CHAR or USER is sending a phone message.
- Every sentence or segment must start and end with the same kind of matching delimiter:
  - Dialogue starts with `"` and ends with `"` (for example, `"spoken text"`).
  - Actions or narration start with `*` and end with `*` (for example, `*action*`).
  - Thoughts start with `(` and end with `)` (for example, `(thought)`).
  - Keep each marked segment clear and self-contained. Never start with one delimiter and end with another. Never nest `*"..."*` or `"*...*"`. Never write bare narration outside markers.
  - Never cross, over-wrap, or split markers incorrectly, such as `"..." * * ... * *` or `* ... * * " ... " *`. Write separate segments as `"..." *...*` or `*...* "..."`. Each segment needs its own opening and closing pair, and adjacent segments must be separated by a space.
- System state blocks must be complete fenced code blocks with both opening and closing ``` delimiters (for example, ```Status ... ``` and ```Emotion ... ```). Never leave an opening fence unclosed. Never mix a state-block name or Markdown state syntax into visible roleplay prose.
